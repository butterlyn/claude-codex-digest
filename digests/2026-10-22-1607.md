## Claude Code

- [ ] **Claude Code 2.1.307 adds `/claude-api api-version`** - Run it to move Claude API code to API version `2026-10-21`. The same release adds a `claude_code.safety_event` OpenTelemetry event for each tool call that a permission rule, auto mode, a safety check, a hook or the sandbox stopped or prompted, and `@claude review stop` (also `off`, `pause`) for Code Review. The docs list `api-version` under the `/claude-api` skill arguments, which need v2.1.307 or later. - [ ] **New `sandbox.allowNestedUserNamespaces` setting for Linux and WSL2** - Set it to `true` only if Chromium, Electron, nested bubblewrap or `unshare` fail inside the sandbox. It turns off a security boundary, so code from a sandboxed command can end up running outside the sandbox, and protected paths can't be relied on. For rootless Podman or Buildah, use `excludedCommands` instead.
