## Claude Code

- [ ] **2.1.301 adds a usage-limit cap for unattended retry mode** - If you use `CLAUDE_CODE_RETRY_WATCHDOG`, set `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS` so requests end instead of waiting on a far-off reset. Also adds the `%` vim motion. [Claude Code changelog](https://code.claude.com/docs/en/changelog)
